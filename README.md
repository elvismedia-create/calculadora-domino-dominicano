# Calculadora Domino Dominicano

App React con Vite para llevar marcador de domino dominicano, sumar rondas por equipo y calcular puntos desde la camara.

## Desarrollo

```bash
npm install
npm run dev
```

Abre `http://localhost:5173/`.

## Deploy en Vercel

Configuracion recomendada:

- Framework Preset: `Vite`
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

La camara funciona en Vercel porque el sitio se sirve por HTTPS.
